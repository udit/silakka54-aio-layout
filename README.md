# Silakka54 All-In-One Layout
This layout will help you switch from a full size QWERTY keyboard to an alt layout on Silakka54 without switching back and forth between old and new keyboards to be productive.
- There are 3 base layers
- Use the QWERTY layer as base until you get familiar with column staggered keys and [home row mods](https://precondition.github.io/home-row-mods)
- Switch to Alt layer for practicing new layout on [Keybr](https://www.keybr.com/) and [Monkeytype](https://monkeytype.com/)

This layout takes inspiration from [getreur's QMK keymap](https://github.com/getreuer/qmk-keymap) and [Miryoku layout](https://github.com/manna-harbour/miryoku). Visualizations are taken from [Thomas Kelpen](https://github.com/tmfsd/Silakka54-layout)

> [!NOTE]
> This layout is designed for Windows, you need to tweak it for other OS

![Silakka54](/images/Silakka54.jpeg)

## Gaming Layer
- QWERTY layout without any home row mods
- Func layer can be accessed from both halves

![](/images/0.png)

## Alt Layout
- I use [Gallium](https://github.com/GalileoBlues/Gallium), but you can use [any of the new ones](https://layouts.wiki/guides/start/intro/)
- Home row mods on both halves
- Holding thumb keys activates other layers

![](/images/1.png)

## Numpad Layer
- Hold backspace to activate this layer
- Access navigation and symbol layer without leaving numpad layer

![](/images/3.png)

## Symbol Layer
- Hold Tab or Enter to activate this layer
- Common symbols and operators are on the left half so those can be accessed from the numpad layer
- Common programming symbols are close to home row
- and common bigrams +=, -=, *=, -> are inward rolls

![](/images/4.png)

## Navigation Layer
- Hold space to activate this layer
- Use layer lock to use arrow keys without using the other hand while watching videos

![](/images/5.png)

## Mouse Layer
- Hold escape to activate this layer
- Clicks are also on the left hand to enable dragging

![](/images/6.png)

## Function Layer
- Hold delete or dedicated keys in gaming layer to activate this layer

![](/images/7.png)
